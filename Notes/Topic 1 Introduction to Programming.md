# Topic 1: Introduction to Programming

## 1. What is a Computer Program?

- A **program** is a set of instructions written to tell a computer what to do.
- A computer cannot think on its own — it only does exactly what it is told, step by step.
- Writing a program is called **programming** or **coding**.
- The person who writes programs is called a **programmer**.

## 2. Why Do We Need Programs?

- Computers are very fast and accurate, but they have no intelligence of their own.
- To make a computer perform a task (calculation, printing a message, storing data, etc.), we must give it clear, step-by-step instructions.
- These instructions must be written in a language the computer can understand.

## 3. What is a Programming Language?

- A **programming language** is a set of rules and words used to write instructions for a computer.
- Just like humans use English or Hindi to communicate, computers understand only certain "languages."
- Examples of programming languages: C, C++, Java, Python.

## 4. Levels of Programming Languages

Programming languages are grouped into three main levels:

### a) Machine Language

- The lowest-level language.
- Written using only **0s and 1s** (binary code).
- This is the only language a computer's processor directly understands.
- Very difficult for humans to read or write.

### b) Assembly Language

- Uses short codes called **mnemonics** (like `ADD`, `SUB`, `MOV`) instead of pure binary.
- Easier than machine language, but still close to hardware.
- Needs a translator program called an **assembler** to convert it into machine language.

### c) High-Level Language

- Uses English-like words and mathematical symbols (e.g., `if`, `for`, `+`, `-`).
- Easy for humans to read, write, and understand.
- Examples: C, C++, Java, Python.
- Needs a **compiler** or **interpreter** to convert it into machine language.
- **C is a high-level language.**

## 5. Compiled Languages vs Interpreted Languages

| Point           | Compiled Language                                            | Interpreted Language                            |
| --------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| Meaning         | Entire program is translated into machine code **before** running | Program is translated and run **line by line**  |
| Translator used | Compiler                                                     | Interpreter                                     |
| Speed           | Faster (translation done once)                               | Slower (translation happens every time it runs) |
| Errors shown    | All errors shown together after compiling                    | Errors shown one at a time, as encountered      |
| Examples        | C, C++                                                       | Python, JavaScript                              |

- **C is a compiled language.**
- This means the full C program is first converted into machine code by a **compiler**, and then it is run.

## 6. Key Points to Remember

- A program = set of instructions for the computer.
- A programming language = a way to write those instructions.
- Machine language → Assembly language → High-level language (increasing ease for humans).
- C is a **high-level, compiled** programming language.
- Compiler converts the whole C program into machine code at once, before execution.

## 7. Quick Recap (One-Line Points)

- Program = instructions for a computer.
- Programmer = person who writes programs.
- Machine language = 0s and 1s.
- Assembly language = short codes (mnemonics).
- High-level language = English-like, human-friendly.
- Compiler = translates full program before running (used by C).
- Interpreter = translates and runs line by line (used by Python).
