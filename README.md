# Concepts of Programming Languages (CPL)

Welcome to the **1st Semester AIML Repository** for *Concepts of Programming Languages*. This repository serves as a structured collection of lecture notes, lab assignments, algorithmic logic, and code implementations designed to build a strong foundation in core programming paradigms and procedural logic.

## 📌 Topics Covered

### 1. Concepts of Programming

- Programming Paradigms (Imperative, Procedural, Object-Oriented)
- Translation Process: Compilers, Interpreters, Assemblers, and Linkers
- Memory Layout of a Program (Stack, Heap, Data, and Text Segments)
- High-Level vs. Low-Level Execution

### 2. Algorithms & Problem Solving

- Problem Decomposition & Flowcharting
- Algorithm Analysis: Time & Space Complexity Basics
- Standard Problem Patterns (Searching, Sorting, Number Theory)

### 3. Pseudocode

- Standard Pseudocode Notations & Structured Logic
- Control Structures in Pseudocode (Sequence, Selection, Iteration)
- Stepwise Refinement & Dry Run Techniques

### 4. C Programming Fundamentals

- Structure of a C Program & Compilation Stages
- Data Types, Variables, Literals, and Type Casting
- Operators (Arithmetic, Relational, Logical, Bitwise) & Precedence

### 5. Core C Programming Concepts

- **Control Flow:** `if-else`, `switch-case`, `for`, `while`, `do-while`
- **Modular Programming:** Functions, Pass-by-Value vs. Pass-by-Reference, Scope & Storage Classes
- **Arrays & Matrices:** 1D/2D Arrays, Matrix Multiplication, Vector Operations
- **Memory Management:** Pointers, Pointer Arithmetic, Dynamic Memory Allocation (`malloc`, `calloc`, `free`)
- **Data Organization:** Structures, Unions, File I/O Handling

## 🛠️ Getting Started

### Prerequisites

- **Compiler:** `gcc` or `clang`
- **Text Editor / IDE:** VS Code, Cursor, or any C-compatible editor
- **Version Control:** Git

### Installation & Execution

1. **Clone the repository:**

   Bash

   ```
   git clone https://github.com/your-username/aiml-cpl-sem1.git
   cd aiml-cpl-sem1
   ```

2. **Compile a C program:**

   Bash

   ```
   gcc 03_C_Basics/hello.c -o hello
   ```

3. **Run the executable:**

   Bash

   ```
   ./hello
   ```
